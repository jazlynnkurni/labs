# Journal: Is the AI music argument the same one?

It is the same argument on the surface and a different one underneath. The synthesizer objection was about the sound, which did not come from a body, and the drum machine objection was about the hand, which no longer kept time. Both complaints faded because a person still had to decide what to play. The instrument changed, the choosing did not.

AI music moves the choosing. When a model suggests the melody and writes the lyric, the human contribution can shrink to a prompt and a verdict, and the part people were defending all along, the decision about what the song should be, is the part that has been handed over. I concede that a producer picking from generated takes is still choosing, so this is a matter of degree. Yet degree is the whole point. The earlier tools removed labour from music. This one can remove the author.
